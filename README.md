# Nigeria Agricultural Commodity Market Price Analysis

A reproducible Python exploratory data analysis (EDA) project using Pandas, NumPy, Matplotlib and Seaborn.

## Important dataset disclosure
The included `market_prices_illustrative.csv` is **synthetic demonstration data**. It was generated for this portfolio project and is not an official or verified record of Nigerian market prices. Do not use its charts as evidence of actual market conditions. Replace it with a properly sourced dataset before making real-world claims.

## Project contents
- `data/`: included illustrative CSV
- `notebooks/`: step-by-step Jupyter Notebook
- `src/`: reusable analysis script
- `visualizations/`: generated charts and summary tables (created when you run the analysis)

To run the script:
```bash
python src/analyze_market_prices.py
```

## Skills demonstrated
Data inspection, data cleaning, missing-value handling, duplicate removal, descriptive statistics, grouping and aggregation, time-series exploration, charting and communicating limitations.

## Before publishing
Replace the illustrative CSV with verified data, document the source and collection dates, update the analysis, and write findings supported by that source.
